# Living Docs

This is the repository's living-documentation wiki: how the codebase works
today, built from verified repo evidence (code, tests, config, and specs).

## Categories

- [domains/](domains/index.md) — what the system is and does: product areas,
  modules, runtime systems, integrations, workflows.
- [conventions/](conventions/index.md) — how the repo usually does things:
  naming, layout, testing style, error handling, state patterns.
- [standards/](standards/index.md) — rules and contracts to preserve: APIs,
  schemas, security, compatibility.
- [strategies/](strategies/index.md) — change-over-time guidance: rollout,
  rollback, migrations, release flow, deprecation, scaling.

See [spec-index.md](spec-index.md) for which implemented specs map to which
pages here.
